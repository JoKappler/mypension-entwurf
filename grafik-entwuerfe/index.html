Netto-Vergleich: drei Vorschläge für die Grafik

Beispiel: 40 Jahre, 500 € im Monat, 50.000 € Einkommen, verheiratet. Zahlen aus dem Rechner, Stand 24.11.2026.

Bitte einen Favoriten wählen: A, B oder C.

A: BalkenB: VerlaufC: Säulen

Vorschlag A · Balken

Ein ProduktAlle Produkte

Liest sich wie eine Rangliste: Name links, Zahl rechts in einer Flucht, Balken darunter ab 0 · schwächer: nahe Beträge ergeben fast gleich lange Balken · Aufwand klein.

Vorschlag B · Verlauf

Ein ProduktAlle Produkte

Eine Aussage: so viel zahlen Sie ein, so viel wird daraus, für das gewählte Produkt · schwächer: zeigt nur ein Produkt auf einmal · Aufwand groß (Rechner muss Jahreswerte liefern).

Vorschlag C · Säulen

Ein ProduktAlle Produkte

Fünf Säulen auf einer Grundlinie, Zahlen in einer Linie darüber · schwächer: Knopf erst nach Antippen des Namens, am Handy wird daraus eine Liste · Aufwand mittel.

Einschätzung

Am klarsten bleibt A: Name und Zahl in einer Zeile, darunter ein ruhiger Balken ab 0, das liest jeder wie eine Rangliste, auch am Handy. B ist jetzt die ruhigste Ergänzung für den zweiten Blick auf ein Produkt (so viel zahlen Sie ein, so viel wird daraus), C die schönste Übersicht am Computer.
